# 📰 BBC News Text Classifier

An interactive Machine Learning web application built using Streamlit and Scikit-learn that predicts the category of news articles using the Naive Bayes algorithm.

---

## 🚀 Features

- Predicts news category from user input text
- Real-time text classification
- Interactive web interface using Streamlit
- Uses CountVectorizer for text preprocessing
- Multinomial Naive Bayes model for classification

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- Machine Learning
- NLP (Natural Language Processing)

---

## 📂 Dataset

BBC News Classification Dataset
